# FLOW MATRIX
Neon color-connection puzzle. Pure HTML/CSS/JS, no backend.
- Main game: Easy, Medium, Hard (10 levels each), timer, stars, hints, dashboard, achievements.
- Endless Flow: unlocks after all 30 levels (Easy, Medium, Hard, never-ending).
- Progress is saved in LocalStorage (same browser and device).

## Deploy on GitHub Pages
1. Create a public repo and upload everything in this folder (`index.html` at the root).
2. Settings → Pages → Deploy from a branch → `main` / `(root)` → Save.
3. Your game: `https://<username>.github.io/<repo>/`

Keys: Esc pause · R reset · U undo.
